\section{Protocol}

The maintained protocol is \texttt{FEVC-ALPHA-BENCH-V2}.

\begin{itemize}
  \item Each backend/case pair starts in a fresh Stata process.  The first
  observation is labeled cold; runs two through four form the warm median.
  \item Stata timer 80 surrounds the complete public command.  Timers 91--98
  are forbidden because the Mata implementation owns them internally.
  \item Stata/MP uses four processors.  Synthetic inputs are deterministic:
  six stored rows per worker, three links per worker, integer frequency
  weights, explicit target weights, stable deletion IDs, and a fixed probe
  ordering.
  \item Every accepted row proves convergence under the complete-original-
  system residual threshold, the target accounting identity, absence of
  \texttt{e(V)}, statistical repeatability within a backend, \texttt{e(sample)},
  dataset signature, sort-RNG state, and complete caller RNG restoration.
  \item Process peak resident set size comes from the operating system.  Rust
  additionally emits the additive native phase receipt
  \texttt{VCKSS-NATIVE-PHASE-PERF-V1}.
  \item The CZ18 input never leaves SCC.  Its retained-design SHA-256 is
  \texttt{1748ca2a6a46f248e05c0329407e7e7708ec7628c1ffce5f0e06ee264bdf0575}.
\end{itemize}

converged cells; a resource rejection, corrupt receipt, or typed failure is
reported rather than dropped or rerouted.
