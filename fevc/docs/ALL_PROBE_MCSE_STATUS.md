## Mathematical and runtime guarantees

Primitive order is worker variance, firm variance and worker–firm covariance.
The fourth target uses `(1,1,2)` without treating covariance as twice itself.
Target parity folds use their own means and the cross-stage interaction term
has coefficient one. Whole physical-copy/deletion-unit and combined mover/
stayer contributions are summed before covariance products. The conditional
joint covariance contracts back to the four unchanged legacy conditional MCSEs.

Independent tests cover fixed-R five-moment derivatives, full varying-control
block inverses, nonlinear copy averaging and pullbacks, correlated matrix
scores, odd folds, negative signed terms, exact-zero directions, rescaling and
scaled PSD policy. Exact enumeration includes a pure-interaction example in
which the intentionally naive plug-in formula doubles the true variance.
Normalized numerical derivative and exact algebra gates remain `1e-9` and
`1e-11`; no scientific or residual threshold was relaxed.

The Rust test-only full `U_r`/`L_t` cache is independently checked by dense
Python complex-step contractions. It includes unequal R/T, both deletion and
nuisance modes, controls, frequencies, target mass and combined stayers. It is
`cfg(test)` only, and the Python-dependent test is run explicitly rather than
silently skipped. Mata uses an independent expanded-copy dense finite-
difference oracle, with both nuisance/deletion modes and a 42042-copy stress.
A maintained 13-copy fixture injects frozen Counter-V1 leverage/target atoms
into Mata's test matrix provider: point, conditional, leverage and raw total
covariance agree at normalized `1e-11` with the native command.

Production generic state stores two derivative scalars per physical observation
copy and three per observation row, six compensated fold means per observation
row/group and six scores per leverage probe. Mata also retains six fixed fold
weights per physical observation copy for quad crossproduct contractions.
Compressed state uses original deletion units and exact target strata without
conflating them with coefficient cells. Replay is capped at four directions in
Rust and eight in Mata, and never exceeds the admitted point leverage width.
Rust observation replay reuses packed Counter-V1 words and contracts copy
pullbacks during RHS construction; match-only Rust state allocates no
observation copy derivatives. Fixed-size prediction/RHS/atom scratch is reused.
Point draw arithmetic and conditional MCSE are preserved; replay re-evaluates
original atoms and does not create independent estimator draws.
Mata batches the existing analytic derivative kernel, prepares bounded panel
gathers, and contracts whole-probe scores with quad reductions. Compressed
cursor batches retain the original per-probe draw calls while capturing and
restoring caller state once per batch. The private module is API 4; mathematical
and native numerical V1 semantics remain unchanged. See the
[Mata optimization evidence](MATA_ALL_MCSE_OPTIMIZATION_2026-09-30.md).

Mata owns the original unopened replay cursor or restores the original leverage
stream start; both saved post-point streams are restored afterward. The outer
command restores RNG algorithm, stream, complete state, data/sample and sort
state on success, withholding and failure. Default requests keep the legacy
conditional diagnostic. Exact selection posts zeros with no probe/replay work.

Statuses distinguish usable local covariance, scaled tolerance-level PSD
cleanup, material non-PSD raw covariance, nonsmooth adjustment, nonfinite
derivatives and numerical replay failure. Raw signed matrices remain visible;
usable matrices/MCSE are missing when unavailable. Numerical replay failures
retain the accepted point. Allocation, transport corruption, invariants and
UserBreak remain command failures. No `e(V)` is created by this option.
