## Runtime and source boundary

The installed Stata path contains Mata source only. It loads no C, C++, or
Fortran helper; no Stata plugin, MEX file, executable, subprocess, or binary
interchange layer participates in hierarchy construction or application.
"Native hierarchy builder" in this milestone means a builder implemented
inside Mata and called directly from the generated Mata namespace.

The official C/MEX CMG implementation is used only by separately scheduled
MATLAB comparison jobs. It is never staged into the Stata package or called by
the Stata benchmark. The inspected upstream version is commit
`8b957ffeb10b8465a3584fceb0265cccc48379e1`; file-level paths and hashes are
recorded in `shared/cmg/docs/UPSTREAM_SOURCE_MANIFEST.yaml`.

API 6 is source-informed and GPL-derived. It is not described as clean-room.
The canonical template and generated namespace artifacts carry the applicable
notices and SPDX identifier. Public distribution still requires a human
review of complete corresponding source, file notices, third-party
boundaries, and data exclusions.

## Algorithmic change

API 6 replaces the scale-limiting hierarchy grouping stage with bulk-Mata
implementations of the official architecture's central ideas:

- a canonical heaviest-neighbor profile and selected forest;
- bounded branch splitting and cycle checks;
- the official one-eighth weak-group repair;
- canonical component-contained aggregate labels;
- exact positive Galerkin contraction;
- a normalized-heavy, component-contained fallback; and
- an API-5 screened-forest specialization for dense ordinary quotients.

The exact degree-three hybrid graph, fixed symmetric quotient-SPD V-cycle,
PCG, estimator, semantic probe contract, route-before-RNG rule, and complete
original worker-plus-firm residual certificate are unchanged. No edge is
sparsified or clipped, and no ridge, pseudoinverse, or component merge is
introduced.

The exactly input-matched official MATLAB job `7222342` also passed. It used
the same DTA hash, P20, seed, and four MATLAB pool workers. Its maintained
MATLAB command took 43.802 seconds, so the registered command-time ratio is
6.96 Stata/MATLAB. Its qacct wall was 399 seconds because the isolated MATLAB

The MATLAB process-tree peak was 10,379,636 KiB and qacct maximum virtual
memory was 49.096 GiB, both inside its 56-GiB envelope.

Computational parallelism is matched at four: Stata verified four actual
processors and MATLAB verified four distinct pool workers with single-threaded
numerical libraries. The CZ18 Stata job reserved 14 scheduler slots at 4 GiB
each to obtain 56 GiB while using four Stata processors; the MATLAB job
reserved four slots at 14 GiB each and used all four as pool workers. Thus the
application-core policy and total memory envelope match, while the scheduler
slot geometry differs.

## Promotion decision

API 6 is retained as an **internal experimental KSS candidate**. It is not
promoted to production or public release. The Mata-only architecture,
correctness, degree robustness, degree-four improvement, setup-scaling,
memory, matched-P20 MATLAB, repeated-RHS, and CZ18 gates pass. Degrees five
through seven are now routine on every admitted balanced and adversarial case.

One planned performance gate is not formally closed: the SCC campaign measured
API-5/API-6 hierarchy setup, but did not run a direct frozen-API-5
complete-command median at the matched degree-two/three sub-minute cells. API
6 deliberately dispatches those dense ordinary quotients to the retained API-5
screened forest, and local setup measurements show no material cliff, but that
is not a substitute for the predeclared complete-command `<=10%` A/B gate.
This missing comparison blocks production promotion; it does not weaken the
correctness or SCC qualification results above.

The remaining public gates are a named human mathematical review and a human
GPL/provenance review of notices, complete corresponding source, third-party
boundaries, and data exclusions. PPML integration remains outside this
milestone. No independent-review, theorem, production, or release status is
implied by the completed numerical campaign.
