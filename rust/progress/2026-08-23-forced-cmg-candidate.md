all RHS receipts carry forced-CMG route code 3, while the older V6 route
prefix—including `full_fit_route`—remains deliberately diagonal (2). This is
the same frozen-prefix rule already enforced for requested/selected route and
fallback. The private regression now preserves that contract explicitly.

The public result boundary still requires repair: it must validate the frozen
V6 prefix as diagonal, use V7 as authoritative for the selected route, and
validate every RHS receipt against the V7 selected route. Its memory fence must
likewise use the V7 command-memory receipt for CMG while retaining the stricter
legacy diagonal identities for schema-2 calls.

This file records a candidate, not a qualification claim. The next required
evidence is an exact-SHA `quick` receipt for this checkpoint, a diagnostic
`plugin-build` receipt containing the raw CMG memory fields, and then a
successful exact-SHA `plugin-build` receipt after the result-boundary repair.
