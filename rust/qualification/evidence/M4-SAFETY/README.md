# M4 bounded safety evidence

The Darwin arm64 receipt for source
`041a89e9fbaa0b4893564b3ca8984bc701e2003b` was generated by:

```bash
rust/tools/run_safety_checks.sh --receipt RECEIPT_PATH
```

It covers strict-provenance Miri execution of the bounded plugin library,
generation-safe registry, malformed/capacity FFI, pre-access memory admission,
callback, UserBreak, and stayer-interruption/release cases. It also covers the
Stata C shim under AddressSanitizer and UndefinedBehaviorSanitizer and compiles
the public ABI compatibility fixture with warnings as errors.

The full numerical library and the exact-stayer dense spectral solve are not
Miri claims: the interpreter changes floating-point behavior and is
impractically slow for the dense solve. Native Rust bitwise/numerical tests and
the macOS/Stata exact-stayer lifecycle remain mandatory and passed in their
separate qualification lanes. Fuzzing, dependency/advisory review, license
inventory, SBOM, Windows, and public release are not covered by this receipt;
the completed automated fuzz and supply-chain claims have their own
source-bound receipts beside this directory.

The companion Darwin arm64 fuzz receipt for source
`a091b37123c16697750af5578c905b7ff172b710` covers the V1/V2/V3
request-capability ABI with randomized semantic tuples, header sizes and
versions, reserved fields, null input/output pointers, and short/exact/long
output capacities. The pinned 60-second libFuzzer run executed 2,654,939
inputs at 43,523 executions/second, added 556 temporary corpus units, peaked
at 506 MB RSS, and produced zero crash, timeout, or leak artifacts. The
expanded corpus, raw output, target directory, and artifacts were deleted; the
locked harness, seed corpus, source-bound receipt, and corpus hash are tracked.
