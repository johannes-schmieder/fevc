# KSS-NUMOPT-2 evidence

This directory contains aggregate, source-bound evidence for Optimization
III. It contains no input DTA, retained-row artifact, private identifier, or
other row-level data.

- `local/` preserves the immutable Optimization II and commit-bound
  Optimization III P200 CSVs, the differential validator receipt, and the
  validated 1/2/4/8/16 batch-width calibration.
- `matched/` preserves scheduler, application, resource, residual, and
  external-validation receipts for the matched CZ18 P200 jobs. The underlying
  restricted input remained on `/projectnb/welfgr/`.
- `synthetic/` preserves the same aggregate evidence for each deterministic
  public scale task. Synthetic input files were generated under SCC scratch
  and were not collected.
- `model/` is generated by `kss_bc/benchmarks/model_numopt2.py` after every
  required synthetic task validates.
- `matlab/` preserves externally validated aggregate receipts for maintained
  MATLAB runs on the same synthetic task shapes. Its `failed/` subdirectory
  retains pre-estimation harness failures under their original source and job
  identities. Corrected MATLAB estimates are descriptive because the target-
  weight, RNG, and tolerance contracts differ from KSS.
