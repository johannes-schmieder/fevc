## 3. What is implemented

Commit `48b478b` introduced API 19's experimental compressed path. It keeps
three distinct canonical indices:

1. coefficient cells: unique worker–firm coordinates;
2. deletion units: actual match IDs, including multiple IDs at one cell;
3. exact target-scale strata: never grouped by tolerance.

The eligible path is deliberately narrow: improved JLA, match deletion, no
controls, every deletion unit contained in one coefficient cell, exact target
strata, total physical mass below `2^53`, no more than 16,383 probes, a
registered Stata runtime RNG contract, and an admitted resource forecast.
Ineligible designs use the unchanged generic engine only if its own pre-RNG
memory and wall forecast passes. Otherwise the command returns a typed
pre-RNG rejection.

The compressed path includes:

- canonical cell/unit/stratum construction;
- compressed FE transpose, Schur action, diagonal preconditioning, worker
  reconstruction, RSS, CMG graph input, and full residual calculation;
- exact direct binomial frequency sums where their distributional conditions
  hold;
- scalar no-control match correction and fused target contractions;
- native disk-backed Stata `preserve`/`clear`/`restore`, with caller data and
  exact `e(sample)` restored;
- separate import/selection, compression-transition, numerical, and
  restoration memory/timing receipts;
- pre-RNG compressed and generic resource admission;
- deterministic well-connected and ring replication fixtures;
- scalar SCC KSS and maintained-MATLAB orchestration and validators.

The exact match specialization is:

\[
D_g=E_g\left(m_g^{-1}+B_gm_g^{-2}-V_gm_g^{-3}\right),\qquad
K_c=\sum_{g\to c}Y_gD_g,
\]

with target correction draw \(\sum_c K_cz_c^2\). It inherits every existing
definition, conditioning gate, reciprocal-residual gate, coefficient-one
finite-projection formula, and typed failure for \(B_g,V_g,m_g\).

Every fit, leverage, and target solve certifies the complete original normal
equations:

\[
r_w=b_w-\left[d_w\alpha_w+\sum_{c:w_c=w}F_c\gamma_{f_c}\right],
\]

\[
r_f=b_f-\left[e_f\gamma_f+\sum_{c:f_c=f}F_c\alpha_{w_c}\right].
\]

The solve uses the full-firm zero-sum quotient, displays the last firm at zero
only afterward, includes the grounded firm's original equation, and divides
by the original RHS Euclidean norm (absolute for a zero RHS). The acceptance
threshold is `max(1e-11,10*tolerance())`. A graph residual is insufficient.

## 12. Optimization gates and stopping rule

Rank changes by measured complete-command payoff:

- canonical compression and the scalar/fused target kernel are already the
  primary arithmetic, memory-traffic, pass-count, and memory reductions;
- simple low-risk changes may remain with a repeatable 5% complete-command
  gain or a demonstrated scale-enabling memory/pass reduction;
- solve-ahead, recycled PCG, block PCG, or similarly complex mechanisms need
  at least 10% repeatable complete-command improvement after dense algebra;
- iteration-count reductions without wall-time reductions do not qualify;
- do not re-enable the old reusable CMG workspace merely because it exists;
  it was slower in measured evidence.

Stop the optimization search after the mandatory well-connected 4x P200 run
passes within limits and no remaining candidate credibly promises at least 5%
end-to-end improvement or enables an otherwise inadmissible larger scale.
